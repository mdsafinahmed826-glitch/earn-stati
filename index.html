  3. গ্রাহকের যেকোনো মেসেজের বিপরীতে নিচে উৎপন্ন Graph API Payload স্বয়ংক্রিয়ভাবে ফেসবুক সার্ভারে প্রেরিত হবে: https://graph.facebook.com/v18.0/me/messages?access_token=YOUR_PAGE_ACCESS_TOKEN
